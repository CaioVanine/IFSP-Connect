IFSP-Connect.

Nicoly de Castro Lopes
• Curso:

• Objetivo do IFSP Connect:
Ser uma plataforma web que apresenta as principais informações sobre o IFSP campus Guarulhos com recursos que facilitem o encontro e compreensão destas informações para pessoas que já estão inseridas na rotina do campus e usuários de fora que tem interesse em conhecer mais da instituição..
• Tecnologias que serão utilizadas:
HTML, CSS e JavaScript.
